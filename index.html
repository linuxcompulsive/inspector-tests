GUIA D'ÚS

Com funciona?

Un programa HTML + JavaScript estàtic. Funciona a GitHub Pages, sense registre ni serveis externs.

01

Carrega les preguntes

Fes servir Preguntes → Importar fitxer per carregar un JSON o CSV, o afegeix preguntes amb l'editor incorporat.

02

Tria el teu temari

Selecciona tot el temari, un bloc complet o un tema concret. Tria entre 10, 30 o 50 preguntes (sense repeticions).

03

Respon i revisa

Passa d'una pregunta a una altra, deixa'n en blanc si vols i, en finalitzar, revisa errors, encerts i explicacions.

04

Guarda el banc a GitHub

Exporta el banc en CSV i substitueix preguntes.csv al teu repositori. Es carregarà automàticament a PC i mòbil.

Format de les dades

El programa carrega automàticament preguntes.csv des de GitHub Pages. No cal convertir-lo a JSON.

La primera fila ha de ser aquesta capçalera, en aquest ordre:

id,bloc,tema,enunciat,opcio_a,opcio_b,opcio_c,opcio_d,correcta,explicacio,origen

Una pregunta ocupa una fila. correcta és una lletra A/B/C/D. Les columnes explicacio i origen són opcionals. CSV en UTF-8; els textos amb comes, cometes o salts de línia s'exporten correctament entre cometes. També pots importar fitxers JSON antics.

Actualitzar preguntes a GitHub

Edita preguntes.csv amb LibreOffice o Excel, desa'l en CSV UTF-8 i substitueix-lo a GitHub. No cal tocar index.html ni app.js. Si tens canvis locals, exporta'ls abans de prémer «Restaurar CSV de GitHub».

Dades i privacitat

Les respostes i els resultats es desen al navegador. GitHub Pages no pot escriure automàticament al repositori: si edites preguntes dins del programa, prem Exportar CSV i penja'l a GitHub manualment. Els resultats de PC i mòbil no se sincronitzen.

Correcció

Una resposta correcta suma un encert; una incorrecta, un error; les no contestades es compten a part. El percentatge és encerts / preguntes totals × 100, sense penalització addicional.
