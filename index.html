GUIA D'ÚS

Com funciona?

Un programa HTML + JavaScript estàtic. Funciona a GitHub Pages, sense registre ni serveis externs.

01

Carrega les preguntes

Fes servir Preguntes → Importar fitxer per carregar un JSON o CSV, o afegeix preguntes amb l'editor incorporat.

02

Tria el teu temari

Selecciona tot el temari, un bloc complet o un tema concret. Tria entre 10, 30 o 50 preguntes (sense repeticions).

03

Respon i revisa

Passa d'una pregunta a una altra, deixa'n en blanc si vols i, en finalitzar, revisa errors, encerts i explicacions.

04

Guarda el banc a GitHub

Exporta el banc en JSON i substitueix preguntes.json al teu repositori. Així es carregarà a qualsevol dispositiu.

Format de les dades

El fitxer preguntes.json conté un objecte amb la propietat preguntes. Cada pregunta ha de tenir aquests camps:

{
  "id": "7.3-001",
  "bloc": 7,
  "tema": "7.3",
  "enunciat": "Enunciat de la pregunta?",
  "opcions": ["Resposta A", "Resposta B", "Resposta C", "Resposta D"],
  "correcta": "B",
  "explicacio": "Explicació opcional"
}

Per importar un CSV, fes servir aquestes columnes: id, bloc, tema, enunciat, opcio_a, opcio_b, opcio_c, opcio_d, correcta, explicacio, origen. El programa detecta automàticament els temes dels fitxers importats. La columna «origen» és opcional i permet mantenir el qüestionari de procedència.

Dades i privacitat

Les respostes, els resultats i les preguntes editades es desen localment al navegador. No es transfereixen a cap servidor. GitHub Pages no pot escriure automàticament al teu repositori. Si vols actualitzar el banc comú, cal exportar-lo i pujar el fitxer manualment. Les estadístiques de PC i mòbil no se sincronitzen.

Correcció

Una resposta correcta suma un encert. Una resposta incorrecta suma un error. Les no contestades es compten a part. El percentatge és encerts / preguntes totals × 100, sense penalització addicional.
